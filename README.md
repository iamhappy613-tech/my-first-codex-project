# 词间 · Wordspace

一个轻量、浅色主题的单页背单词应用。纯 HTML / CSS / JavaScript，无依赖、无构建步骤，离线也可使用。

## 打开预览

下载或克隆仓库后，直接用浏览器打开 `index.html`，只需要这一个文件。样式、脚本和词库都已内嵌，不会因预览器无法加载关联文件而失效。

也可以在仓库目录运行 `python3 -m http.server 8000`，再在该机器的浏览器访问 `http://localhost:8000`。手机预览可将 `index.html` 放到静态网站托管服务；或让手机与电脑在同一局域网，访问电脑 IP 的 8000 端口。

## 使用方式

- 点击卡片（或聚焦卡片后按空格）翻面，查看中文释义、英文例句和中文翻译。
- 点击“认识” / “不认识”，或按键盘右 / 左方向键作答。
- 在上方选择第 1–7 天；前 6 天各学 43 个词，第 7 天学 42 个，合计 300 个词，互不重复。天数可自由切换，不受日历日期限制。
- 当天第一轮完成后，只将当天不认识的词按原顺序额外复习一轮。
- 当天完成后显示当天第一轮认识数（满分 43，第 7 天满分 42）、首次掌握率、复习后记住的词数和仍待巩固的单词。复习不会重复增加第一轮得分；第二轮不认识的词不会无限循环。完成代表学过当天全部卡片和一次错词复习，并不表示已掌握所有词。
- “重学当天”只清空选中这一天的记录，其他天不变；学习中重学需要确认。结果页可重学当天或选择“学习下一天”，最后一天不再显示下一天按钮。

词库位于 `index.html` 内嵌脚本的 `words` 数组中。无需账号、API 或外部资源；学习记录自动保存在当前浏览器的 `localStorage`，包括选中的天数、每天第一轮作答、错词复习和完成结果，刷新或下次打开可继续。记录不跨设备、浏览器或网站地址同步；清理网站数据会删除记录。浏览器不允许存储时会提示，并降级为当前页面内存，仍可正常学习。

## 词库说明

收录 300 个适合四级复习的常用词，覆盖学习、工作、社会、科技、环境等主题，保留原有 30 个词，并按字母排序。每个词都有音标、中文释义、英文例句和中文翻译。这是人工精选的常见词集合，不是基于指定真题语料统计出的官方频次榜，也不等于四级全部词汇。

页面底部的“查看词汇清单”默认显示当天词汇，也可切换到全部 300 词，支持英文、中文搜索。搜索和切换查看范围不会改变学习进度。仓库内的 `VOCABULARY.md` 提供同一份 300 词清单。

## 文件
