# 词间 · Wordspace

一个浅色主题、适配手机的背单词应用。纯 HTML / CSS / JavaScript，样式、脚本及 300 词全部内嵌在 `index.html`，无依赖、无构建步骤。学习功能离线可用；英语朗读使用浏览器及系统提供的语音能力。

## 打开预览

用浏览器打开 `index.html` 即可。也可在仓库目录运行 `python3 -m http.server 8000`，再在运行服务器的机器上访问 `http://localhost:8000`。

线上通过 GitHub Pages 部署，后续更新推送至 `main` 后按现有 Pages 配置自动部署。

## 弹性学习计划

- 每天最多安排 **43 个不同单词**，包括顺延词和新词；如果都能掌握，300 词大约 7 个学习日完成。
- 卡片点击翻面，查看释义和双语例句。点击“认识 / 不认识”作答，也可使用键盘右 / 左方向键。
- 当天第一轮不认识的词再复习一轮。第一轮或复习中选择“认识”才计为掌握；复习后仍不认识的词继续顺延。
- 点击“今天先到这，剩余顺延”即可提前结束当天，**未学完和仍未掌握的词优先进入下一天，再用新词补足 43 个**。因此新词也可能推迟，而不会额外堆叠一天的任务。
- 跨浏览器本地日历日期后，重新打开页面、回到页面或再次操作时会自动顺延。若只是打开过、还未开始作答，不会凭空多记一天；隔多天才回来，也只接续一个新的学习日。
- 学习时间没有 7 天上限：第 7 天仍有未掌握词，就安排第 8 天、第 9 天……直到 300 词都已掌握。下一天可以提前开始。
- 历史日期保留当时的得分和顺延记录，只能查看，避免修改历史导致当前任务重复。未来日期逐日开启。
- 当天结果显示第一轮认识数、首次掌握率、复习记住数和顺延词数。未作答的词不算认识，复习不重复增加第一轮得分。
- “重学当天”清空当前日作答，并将这一组词重新置为未掌握；其他日期与其掌握词保留。学习中重学会先确认。

例如，今天安排 43 词，只掌握了 19 词（1 词不熟，23 词未学），明天先安排这 24 词，再加入 19 个新词，仍然只学 43 个词。当前、顺延和未分配任务都不会重复或漏掉词。

## 英语读音

- 卡片下方提供“听单词”“听例句”和“停止”按钮。
- 完整词表中的每个英文单词都可点击朗读，每条英文例句也有独立的“听例句”按钮，覆盖全部 300 词及 300 个例句。
- 使用浏览器 Web Speech API，优先选择美式英语语音，其次英式或其他英语语音，语速为 0.85。不会朗读中文释义或中文翻译。
- 每次播放前重新读取可用语音，兼容语音列表延迟加载。重复播放会停止前一段，切换词或日期也会停止旧音频。
- 语音不会自动播放，需要点击按钮；不需要账号或 API 密钥。
- 发音由设备及浏览器提供，并非内置 MP3。设备需要可用的英语语音，有些系统需联网下载英语语音包；不支持或播放失败时会明确提示，学习功能不受影响。

## 进度与旧版兼容

记录自动保存在当前浏览器的 `localStorage`，包括掌握词、待安排词、每天的作答记录与所查看的日期，刷新或下次打开可继续。不跨设备、浏览器或网址同步；清理网站数据会删除记录。不能使用存储时会提示并降级为当前页面内存。

从固定 7 天版本升级时，会自动保留此前第一轮或复习中“认识”的词，将其余词重新纳入弹性安排，不要求从零开始。旧版原始存储记录会保留，新的弹性计划使用独立存储键。旧版的固定日期分组不再决定新计划的每日任务。

## 词库

词库位于 `index.html` 的 `words` 数组。300 个词覆盖学习、工作、社会、科技、环境等四级常见话题，每词包含音标、中文释义、英文例句和中文翻译。人工精选，非官方真题频次排名，也不等于四级全部词汇。

页面底部可查看所选学习日的词汇或全部 300 词，并按英文、中文搜索。词表中可直接听单词和例句。搜索与听读不会改变作答记录。`VOCABULARY.md` 提供同一份中英清单。
