# 词间 · Wordspace

一个轻量、浅色主题的单页背单词应用。纯 HTML / CSS / JavaScript，无依赖、无构建步骤，离线也可使用。

## 打开预览

下载或克隆仓库后，直接用浏览器打开 `index.html`，只需要这一个文件。样式、脚本和词库都已内嵌，不会因预览器无法加载关联文件而失效。

也可以在仓库目录运行 `python3 -m http.server 8000`，再在该机器的浏览器访问 `http://localhost:8000`。手机预览可将 `index.html` 放到静态网站托管服务；或让手机与电脑在同一局域网，访问电脑 IP 的 8000 端口。

## 使用方式

- 点击卡片（或聚焦卡片后按空格）翻面，查看中文释义、英文例句和中文翻译。
- 点击“认识” / “不认识”，或按键盘右 / 左方向键作答。
- 第一轮完成 30 个词后，不认识的词按原顺序额外复习一轮。
- 完成后显示第一轮认识数（满分 30）、首次掌握率、复习后记住的词数和仍待巩固的单词。复习不会重复增加第一轮得分；第二轮不认识的词不会无限循环。
- “重新开始”清空本轮进度（先确认）；结果页“再学一遍”开始新一轮。

词库位于 `index.html` 内嵌脚本的 `words` 数组中。无需账号、API 或外部资源；当前学习进度保存在页面内存，刷新后重新开始。

## 文件

- `index.html`：完整独立页面，包含无障碍结构、响应式样式、翻卡动画、30 个单词及两轮学习逻辑。
