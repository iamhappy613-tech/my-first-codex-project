## 实现取舍

| 决定 | 原因 | 判断错误的影响 |
| --- | --- | --- |
| 沿用当前 main 工作区并按原授权推送 | 用户明确要求提交 main，当前为隔离云端工作区 | 发布缺陷会直接影响正式页面，因此发布前整体审阅并运行回归 |
| 已掌握词的延迟检测独立记录，不静默撤销旧版自评掌握 | 保留历史记录，明确区分认识与检测证据 | 自评分数可能高于实际熟练度，因此界面和 GPT 均明确数据范围 |
| 两个 HTTP 函数使用处理器鉴权，关闭平台统一 JWT 网关检查 | GPT 使用独立口令；管理员令牌向 Auth 验证，再由数据库核对角色；普通数据库接口仍启用 RLS | 处理器若绕过鉴权会暴露数据，已覆盖错误凭据、停用旧令牌、越权及用户 ID 注入检查 |
| 真实邮件、托管鉴权、函数部署和 Plus 调用作为外部验收保留 | 必须通过用户自己的项目及账号操作；当前只有公开配置且网络不通 | 服务端配置错误时功能可能不可用，故验收前不启用正式首页云端模式 |
| 扩展词条依据固定版本来源，释义例句由项目编写核对，不代表独立语言专家认证 | 已记录四级标签、参考频率、发音来源和授权；保留原 300 词任务 | 仍可能存在语言内容误差，支持后续订正，不冒充官方真题排名 |

## 2026-11-21 网页自动学习效果检测更新

新增已学词检测轮次、词义/例句选词、首次作答报告、错词复习和至少24小时复测提示。每轮最多10个不同目标词，不改写原有自评掌握、历史得分或推荐采用流程；本地版和云端预览使用相同源代码并保留各自公开配置。

本轮验证：38项 Node 单元测试、24个原有浏览器场景、10个检测交互场景全部通过；1000词在320/390px卡片布局检查通过；`node scripts/embed.mjs --check` 和 `git diff --check` 通过。独立审查发现的连续开轮误算延迟复测、例句多正确选词、可检测词数未即时更新、临时存储失败丢答题、短轮提示与进度显示问题均已通过先失败后通过的回归修正。650px窄屏实际预览还确认检测期间学习卡片按钮不会遮挡选项。

延迟复测使用近期已同步记录叠加本机近期/待同步作答，待服务器返回相同事件ID后再移除本机叠加。RPC仅提交原有4个字段，缓存时间不作为额外接口参数。相同挖空例句支持的另一个词不会作为错误选项；没有安全干扰项时退回词义题。

浏览器自动检查使用独立测试账号与受控接口响应；手动布局预览使用 localhost 测试记录，未向本人正式账号添加测试作答。本次未变更SQL或HTTP函数，未重复运行Docker数据库集成测试。
