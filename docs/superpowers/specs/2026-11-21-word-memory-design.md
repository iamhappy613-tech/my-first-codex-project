# 单词构词与记忆提示

用户要求在每个单词的解释部分增加词根组成说明，帮助记忆。此改动按已有卡片样式直接增加解释字段，不改变学习流程。

- 卡片翻面后，在中文释义与例句之间新增“构词与记忆”；词汇清单和检测答题后的讲解同步展示。
- 整理当前1000词，明确区分词根词缀、合成词、词族联记和整体记忆。不能可靠拆分的词不编造字母拆分，不把词族联系冒充词源。
- 透明构词和派生词用简短中文说明组成与含义；历史词根只在主词典直接核实并记录来源后使用。
- 采用三个互不重叠的数据分片，保留逐词分类、原始说明和参考来源。前端只读本地嵌入的说明，不增加收费模型调用或数据库字段。
- 使用独立说明表按单词ID关联，避免账号词库刷新覆盖提示。无需改变原有词义、例句、学习进度、检测评分或推荐规则。
- 普通卡片和词表采用同一渲染方法；构词不显示在单词正面或检测题干里。屏幕阅读标签在翻面后包含提示。
- 长说明可以自然增高卡片，手机不裁剪、不横向溢出。保留当前浅色样式。

## 方案取舍

选择：基于逐词整理的说明表显示简短构词/词族说明，无法可靠分析时整体记忆。
未选择：按字母前后缀机械猜测；逐次调用模型临时生成；把全部单词都强行拆成词根。

## 验收

1000词分类完整且无重复或未知ID；每条详细说明具有明确类型与非空内容；卡片和词表显示一致；翻面前不泄露说明；账号同步后提示仍保留；现有学习与检测回归通过；两份HTML保持各自公开配置并发布至原网址。
